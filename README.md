# Dr. Durairaj Arjunan Website

Static website for `drdurairajarjunan.com`.

## Run Locally

```bash
npm install
npm start
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
```

The production files are written to `dist/`.

## Custom Domain

The site includes `CNAME` with:

```text
drdurairajarjunan.com
```

See `DEPLOY.md` for the hosting and DNS setup.
